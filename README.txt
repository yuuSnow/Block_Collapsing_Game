# Block Collapsing Game

## 概要
UnityとC#を用いて開発したオリジナルのブロック崩しゲームです。
通常のブロック崩しに加え、ボールの速度変化や特殊ブロック、ビーム攻撃などの独自要素を実装しました。
また、WebGL形式でビルドし、GitHub Pages上でブラウザからプレイできるようにしています。

## プレイURL
https://yuusnow.github.io/Block_Collapsing_Game/

## 開発環境
- Unity
- C#
- GitHub
- GitHub Pages
- WebGL

## 主な機能

### 通常モード
レベルごとに選択してプレイできるモードです。

### チャレンジモード
すべてのレベルを連続で攻略するモードです。

### 特殊ブロック
通常のブロック以外に、ゲーム性を向上させる特殊なブロックを実装しています。

### ビーム攻撃
アイテムを消費することでビームを発射し、ブロックを破壊できます。


## 工夫した点
- 特殊ブロックによって普通のブロック崩しとの差別化を図った
- ビーム攻撃を追加し、プレイヤーが戦略的にプレイできるようにした
- 通常モードとチャレンジモードを実装し、繰り返し遊べる構成にした
- ミッションを作成し、やりこみ要素を追加した
- WebGLビルドを利用してブラウザ上でプレイ可能にした
